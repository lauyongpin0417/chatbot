1. Introduction
Thank you for purchasing the SmartBrew SB-200 automatic drip coffee machine. This manual explains
how to set up your machine, operate it safely, read its technical specifications, and troubleshoot common
issues. Please read this document fully before first use.
2. Package Contents
• 1 x SmartBrew SB-200 coffee machine
• 1 x Removable 1.8 L water tank
• 1 x Reusable mesh filter
• 1 x Measuring scoop
• 1 x Power cable
• 1 x Quick start card
3. Safety Information
Place the machine on a flat, heat-resistant surface away from water sources. Do not immerse the base
unit in water. Always unplug the machine before cleaning. Allow the machine to cool for at least 10
minutes before removing the carafe after brewing. Keep out of reach of children during operation, as the
hotplate and freshly brewed coffee remain hot.

4. Setup Procedure

Follow the steps below in order the first time you use your SmartBrew machine. The diagram illustrates the full setup flow from unboxing to your first brew.

SmartBrew Setup Flow

1. Unbox the machine and remove packaging
2. Rinse the removable water tank
3. Fill tank with fresh cold water
4. Insert paper or mesh filter
5. Plug in and press the Power button
6. Run one cleaning cycle (no coffee)
7. Machine ready to brew

6. Troubleshooting
If your machine is not working as expected, consult the table below first. This table is provided as an image (a flattened bitmap of a table), useful for testing image-based table extraction and OCR.

Troubleshooting Guide

| Issue | Possible Cause | Suggested Solution |
| :--- | :--- | :--- |
| No power | Unit not plugged in / outlet dead | Check the power cable and try a different outlet |
| Weak coffee | Coffee-to-water ratio too low | Use 2 tbsp of grounds per 6 oz of water |
| Machine leaks | Water tank not seated correctly | Remove and reinsert the tank until it clicks |
| Brew cycle stalls | Mineral buildup in the lines | Run the descaling cycle described in Section 5 |
| Burnt smell | New heating element residue | Run two cleaning cycles with water only before first use |

Figure 2. Troubleshooting guide, rendered as an image.

7. Maintenance Schedule
Descale the machine every 60 brew cycles using a 1:3 vinegar-to-water solution, run through a normal brew cycle without coffee, followed by two cycles of plain water. Wash the mesh filter and carafe after every use with warm, soapy water. Wipe the exterior with a damp cloth; never use abrasive cleaners on the hotplate.
