## Frequently Asked Question - RMS

### General

1. I have technical issue in the system, What should I Do?
   For the system error, firstly you need provide details of the error and a snapshot or printscreen of the error. Secondly, upload all the details into the MMU **Service Desk.** Create case and mentioned which module you need for the rectification. e.g Purchasing Module in RMS.

### Grant Proposal

1. How to apply for Internal Funding grant?
   RMC will made announcement the opening of new internal grant proposal submission date in RMS. Submit the application through the RMS.
2. I have a plan to apply external grant, how do I update grant funnel?
   You can go to Grant Proposal module, click add new grant proposal and fill up the proposal idea.

### List Project

1. How do Project Leader/Member get list of their projects?
   List of projects can be seen under the Project Management Module in the List Project.
2. How to check my project status?
   Project Leader /Member shall go to Project List and view the project status .

### New Approved Project

1. For new approved project, what should I do when receiving grants from external sources?
   Project leader shall log into RMS and register the awarded grant detail. A project id will be created base on the information given and further application can be through the RMS

### End Of Project (EOP)

1. When I should prepare the EOP report?
   Project Leader need to start preparing the EOP report 3 months before project end. Refer tu RMS Manual in the Help menu for more details.
2. Who should prepare the EOP report?
   Project Leader should iniate the EOP report and follow to the funder requirement.
3. How to iniate the EOP report?
   Project Leader must update all output result in RMS and other platform if required by the funder, e.g. For FRGS EOP, need to update in MyGrant system.
4. I discovered my grant financial statement is incorect to whom i should update to?
   For reconciattion, Project Leader should liase with Finance Management (FM) team . Contact Ms Azlina (azlina.abdulaziz@mmu.edu.my) and Ms Sharifah Mariam (mariam.syedkadir@mmu.edu.my).

### Change Request

1. How to apply grant extension?
   Project leader needs to get approval from the grant provider and apply through RMS. You need to go to Change Request menu and choose Change Details. You may refer to **RMS User Manual** for more details.

2. I am a project leader for FRGS grant, I would like to extend my grant another six months
   We do not encourage extension of grants since it will affect MyRA score. If extension is really needed you can apply 3 months before the end of the project with very strong justification. Only strong justification will be considered.
   Steps as follows:
   a. Get MOHE approval
   b. Continue the extension application in RMS ( see **RMS Manual** )

3. How to apply change of project leader?
   Project leader needs to apply through RMS. New Project Leader must be current project member. You need to go to Change Request menu, add new request and select Change Project Leader. You may refer to **Change Project Leader** for more details.

4. How to add project member?
   Log in to RMS, need to go to Change Request menu, add new request and select Add/Remove Project Member. You may refer to **Add/Remove Project Member** for more details. For MOHE grant, project leader needs to get approval from the grant provider.

5. How to update for my partial budget disbursement?
   Go to Change Request menu, add new request and select Partial Disbursement. You may refer to **Partial Disbursement** for more details.

### Virement

1. How can I amend the allocation to suit with my new budget plan (within the same vot)?
   Project leader can do Budget Replan through RMS. May refer **Budget Replan** for details explaination.

2. How can I amend the allocation to suit with my new budget plan (inter the vot)?
   Project leader can do virement through RMS. May refer **Virement Guideline** for details explaination.

3. When can virement be done for FRGS?
   Virement can be done after 6 month from the start of the grant and allowed only once in a year

4. May I know how the FRGS virement application process is?
   You need to apply the virement in both systems
   a. Apply virement in the MyGrant
   b. Apply virement in the RMS (see **RMS Manual)** Project leader can do virement through RMS. May refer for details explaination.

   a. For Internal Project (Project Id start with MMUI), is subject to approval of **Renewal MMU Postdoctoral Research Fellow** first.
   b. For External Project (Project Id start with MMUE), Project Leader shall be able to decide renewal directly

2. I am international MMU Postdoctoral, how to apply the visa renewal?

### Purchasing

1. How to do purchase request using grant ?
   i. Identify request item specification
   ii. Identify vendor/supplier. Request quotation and supporting document from vendors (registered vendor is preferred)
   iii. Submit the purchase request in RMS.

2. How to search /get registered vendor?
   Log in to RMS, go to **Registered Vendor List** or can be retrieve in the purchasing request application at add vendor section.

3. What should I do when the Goods had been delivered?
   Project Leader need to complete the Goods receipt (GR) in RMS. Steps as follows
   i. To confirm the billing address in invoice is the **Universiti Telekom Sdn Bhd**
   ii. Fill up the GR details (under Purchasing Module) Refer to **RMS Manual** for further details
   iii. Signed, official stamped on the Invoice and Delivery Order (DO) before uploading into RMS. Submit the GR application's.

### Claim

1. How long it would take to receive payment made through claim?
   In normal cases, it will take 7-14 working days after claim is submitted in the EDS.

2. How to do manual claim through RMS for LOE?
   Log in to the RMS, select active current active project, go to claim module under spending and follow the below steps
   i. Add new claim
   ii. Choose Pre-Approved category(Refer to the **Pre Approved Claim** for further details)
   iii. Choose Stipend Allowance for claim type.
   iv. Key in Approval Reference ID (Refer to LOE reference number e.g. MMU/RMC/GRE/LOE/2030/123456).
   v. key in details of claim.

3. I am Research Helper, how to submit wages claim?
   Research Helper and Consultant need to submit manual claim.
   i. Submit the claim through RMS
   a. Choose Pre-Approved category(Refer to the **Pre Approved Claim** for further details)
   b. Choose Honorarium/Consultation/Professional Fee-External for **claim type** .
   c. Key in Approval Reference ID (Refer to Appointment reference number e.g.MMU/RMC/Research Helper/NEW/2030/123456).
   d. Key in details of claim.

4. I am MMU Postdoc, how to submit claim for Visa processing fees or flight ticket ?
   Submit the claim through RMS
   a. Choose **Require approval** category
   b. Choose **Visa Processing Fee Reimbursement** for claim type
   c. Key in details of claim

5. I am MMU Postdoc, how to submit claim for medical claim ?
   Submit the claim through RMS
   a. Choose **Require approval** category
   b. Choose **Claim below RM500** for claim type
   c. Key in details of claim
